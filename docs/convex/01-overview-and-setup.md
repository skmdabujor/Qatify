# Convex Overview & Setup Guide

> **Official Reference**: [Convex Docs Home](https://docs.convex.dev/home)  
> **Target Framework**: Next.js 15 (App Router, React 19, TypeScript)  
> **Application**: Qatify Dropshipping Store

---

## 1. What is Convex?

Convex is a reactive backend-as-a-service designed for TypeScript and full-stack web applications. Key features include:

- **Automatic Reactivity**: Database queries automatically push new results to connected React clients via WebSockets when underlying data changes without manual invalidation or polling.
- **ACID Transactions**: Every Convex mutation executes as a serializable ACID transaction. No race conditions or conflicting writes.
- **End-to-End Type Safety**: Server schemas and functions automatically generate TypeScript types (`convex/_generated/`) for instant client-side auto-completion.
- **Zero ORM or Server Maintenance**: Functions run serverlessly directly on Convex cloud infrastructure with sub-second deployment.

## 2. Installation & Dev Setup

### Step 1: Install `convex`
Run the following in the Qatify project root:
```bash
npm install convex
```

### Step 2: Initialize Convex Development Server
```bash
npx convex dev
```

When run for the first time:
1. It prompts you to log in (via GitHub or email).
2. It asks to create a new project or link an existing one (e.g. `qatify-backend`).
3. It creates the `convex/` directory in your root folder.
4. It generates `.env.local` containing:
   ```env
   NEXT_PUBLIC_CONVEX_URL="https://your-deployment-name.convex.cloud"
   CONVEX_DEPLOYMENT="dev:your-deployment-name"
   ```
5. It runs continuously in the background, compiling TypeScript functions and syncing schemas.

> [!TIP]
> Keep `npx convex dev` running in one terminal tab, and `npm run dev` running in another terminal tab during development.

## 3. Directory Conventions

Convex standardizes backend files inside the root `convex/` directory:

```text
convex/
├── _generated/            # Auto-generated by Convex (DO NOT EDIT DIRECTLY)
│   ├── api.d.ts           # Type definitions for queries, mutations, actions
│   ├── dataModel.d.ts     # Type definitions for your database schema
│   └── server.d.ts        # Helper functions (query, mutation, action, httpAction)
├── schema.ts              # Database schema definitions & indexes
├── products.ts            # Product catalog queries and mutations
├── orders.ts              # Order placement, tracking & status updates
├── cart.ts                # Cart persistence & sync
├── polar.ts               # Convex Actions for Polar checkout creation & API calls
├── http.ts                # HTTP router for receiving Polar webhooks
└── auth.config.ts         # Authentication configuration
```

## 4. Next.js App Router Provider Setup

Convex uses a React Client Provider to connect components to the Convex real-time network.

### Create `components/providers/ConvexClientProvider.tsx`
```tsx
"use client";

import { ReactNode } from "react";
import { ConvexProvider, ConvexReactClient } from "convex/react";

const convexUrl = process.env.NEXT_PUBLIC_CONVEX_URL;

if (!convexUrl) {
  throw new Error("Missing NEXT_PUBLIC_CONVEX_URL in environment variables");
}

const convex = new ConvexReactClient(convexUrl);

export default function ConvexClientProvider({
  children,
}: {
  children: ReactNode;
}) {
  return <ConvexProvider client={convex}>{children}</ConvexProvider>;
}
```

### Update `app/layout.tsx`
Wrap your application inside the `ConvexClientProvider`:

```tsx
import type { Metadata } from "next";
import ConvexClientProvider from "@/components/providers/ConvexClientProvider";
import { ShopProvider } from "@/context/ShopContext";
import "@/styles/globals.scss";

export const metadata: Metadata = {
  title: "Qatify | Modern Electronics & Gadgets Dropshipping in Qatar",
  description: "Direct Air Express 6-10 Days Delivery across Qatar. Shop trending tech, accessories, and smart devices.",
};

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <ConvexClientProvider>
          <ShopProvider>
            {children}
          </ShopProvider>
        </ConvexClientProvider>
      </body>
    </html>
  );
}
```

## 5. Convex Environment Variables

Variables needed by your backend (such as Polar API tokens and webhook secrets) are stored in the Convex Dashboard or set via CLI:

```bash
# Set Polar Access Token in Convex
npx convex env set POLAR_ACCESS_TOKEN="polar_oat_xxxxxxxxxxxxx"

# Set Polar Webhook Signing Secret in Convex
npx convex env set POLAR_WEBHOOK_SECRET="whsec_xxxxxxxxxxxxx"

# Set Frontend URL for checkout redirect targets
npx convex env set NEXT_PUBLIC_SITE_URL="http://localhost:3000"
```

To view all configured environment variables:
```bash
npx convex env list
```
